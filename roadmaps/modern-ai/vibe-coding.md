# Vibe Coding

## One-liner

The practice of building software by describing what you want in natural language and iterating with an AI agent — Andrej Karpathy coined the term in 2025; in 2026 it's a recognized software development methodology.

## What It Is

**Vibe coding** (coined by Andrej Karpathy, Feb 2025) is the practice of building software by "vibing" — describing what you want in natural language, letting an AI agent generate the code, and iterating through conversation rather than writing code yourself. It overlaps with but is distinct from traditional AI-assisted coding (Copilot autocomplete).

The 2026 spectrum:

| Level | Description | Tools |
|-------|-------------|-------|
| **Pure vibe coding** | Describe, accept, iterate. Don't read code. | Replit Agent, Cursor Composer, v0.dev. |
| **Vibe coding + review** | Generate, skim, accept obvious, review complex. | Cursor + Claude Code + dev background. |
| **AI-assisted coding** | Write yourself; AI helps with snippets. | GitHub Copilot, Cursor Tab. |
| **Agent-driven dev** | Plan + sub-agents + verification. | Claude Code, Codex, Devin. |

Key tools / workflows in 2026:

- **Replit Agent** — vibe coding for full apps.
- **Cursor Composer / Agent mode** — IDE vibe coding.
- **v0.dev (Vercel)** — generate UI from prompts.
- **Lovable / Bolt.new** — full-app vibe coding.
- **Claude Code** — terminal vibe coding with sub-agents.
- **Devin** — autonomous engineer.

## When To Use It

- **Prototyping fast** — vibe coding's home turf.
- **MVP / hackathon** — ship in hours.
- **Boilerplate + scaffolding** — let AI write it.
- **You don't want to write code** — designers, PMs, founders.
- **Greenfield projects** — no existing code to fight.

## When NOT To Use It

- **Production code at scale** — humans must review.
- **Security-critical** — security review essential.
- **Complex algorithms** — AI hallucinates.
- **You don't understand what the code does** — debugging impossible.

## Why It Matters in 2026

Three forces: (1) AI coding tools matured — Replit / Cursor / Lovable produce production-quality prototypes; (2) Non-developers can ship — vibe coding democratized building; (3) The line between "AI-assisted" and "AI-generated" blurred — most production code in 2026 has substantial AI authorship.

Practitioner playbook in 2026: (1) Pick the right tool (Replit for apps, Cursor for IDE, v0 for UI); (2) Describe clearly + provide examples; (3) Iterate on small chunks; (4) Always review the generated code; (5) Test thoroughly; (6) Use version control religiously.
