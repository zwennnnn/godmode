# Modern AI Meta

> **Category:** The frontier tooling for building products with AI in 2026 — Claude Code, vibe-coding workflows, OpenClaw, AI Product Builder, and the Model Context Protocol (MCP) that ties them together.
> **Sources:** [roadmap.sh/claude-code](https://roadmap.sh/claude-code), [roadmap.sh/vibe-coding](https://roadmap.sh/vibe-coding), [roadmap.sh/openclaw](https://roadmap.sh/openclaw), [roadmap.sh/ai-product-builder](https://roadmap.sh/ai-product-builder)

This roadmap covers the *meta* tools and workflows for AI-augmented software development — not the LLMs themselves (covered in [`../ai-ml-llm/`](../ai-ml-llm/)) but the tooling + methodologies + protocols you use on top.

## Quick Decision Guide

### If you code with an AI agent in the terminal

**[Claude Code](claude-code.md)** — Anthropic's official CLI agent; the reference implementation.

### If you build features by "vibe coding"

**[Vibe Coding](vibe-coding.md)** — describe what you want; iterate with AI.

### If you orchestrate multiple AI agents

**[OpenClaw](openclaw.md)** — open-source multi-agent runtime.

### If you're shipping an AI product

**[AI Product Builder](ai-product-builder.md)** — patterns, frameworks, evals, observability.

### If you want agents to talk to tools

**[MCP (Model Context Protocol)](mcp.md)** — the standard for AI tool integration.
