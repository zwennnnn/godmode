## Quick Decision Guide

### If you want the most popular non-React

**[Vue.js](vue.md)** + Nuxt 3 — #2 frontend framework; gentle curve.

### If you're in enterprise / large team

**[Angular](angular.md)** — opinionated + DI + signals; the enterprise default.

### If you love compile-time / minimal runtime

**[Svelte / SvelteKit](svelte.md)** — most loved; runes; zero runtime overhead.

### If you're building content sites (markdown-first)

**[Astro](astro.md)** — zero JS by default; islands; server islands (v5).

### If you want React-like JSX + fine-grained reactivity

**[Solid.js](solidjs.md)** — top of perf benchmarks among React-like frameworks.

### If you want zero-JS-by-default + resumability

**[Qwik](qwik.md)** — instant TTI; novel architecture; best for slow devices.
