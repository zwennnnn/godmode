# Angular

## One-liner

Google's full-featured, opinionated, TypeScript-first SPA framework — the standard for enterprise frontends in 2026, with Signals + standalone components making it modern again.

## What It Is

[Angular](https://angular.dev/) is a TypeScript-based open-source web application framework led by Google. It's opinionated, batteries-included, and the default for enterprise-scale SPAs at banks, insurance, government.

The 2026 baseline is **Angular 19+ / 20+**:

- **Signals** — reactive primitives (similar to Solid / Vue 3 reactivity).
- **Standalone components** — no NgModules required.
- **Deferrable views** (@defer) — lazy loading at template level.
- **SSR + hydration** with Angular SSR (built into Angular 17+).
- **Zoneless change detection** (Angular 20+) — explicit reactivity, faster.
- **Vite + esbuild** — the new build system.
- **Control flow syntax** — `@if`, `@for`, `@switch` (no more `*ngIf`).
- **Material 3** — Angular Material updated to Material You.
- **Strict typing by default**.

Adoption: Angular is the **enterprise default** for large SPAs. Used by Google, Microsoft, Santander, many banks, governments. ~25%+ of professional frontend devs use Angular.

## When To Use It

- **Large enterprise SPA** — Angular's home turf.
- **Long-term maintenance** — Angular's LTS is excellent.
- **Strong typing by default** — TypeScript everywhere.
- **You like opinion + structure** — Angular is opinionated.
- **Material Design** — Angular Material is the reference implementation.

## When NOT To Use It

- **You want flexibility** — too opinionated for some.
- **You want minimal bundle** — Angular apps are larger than React/Vue.
- **Small project** — Next.js / Nuxt / SvelteKit is faster.
- **You hate TypeScript** — Angular requires it.

## Why It Matters in 2026

Angular 19/20 with Signals + standalone components + zoneless change detection made Angular modern again. Angular remains the enterprise default for large SPAs at banks, insurance, government. Strong typing by default + DI + opinionated structure = maintainable at scale.
