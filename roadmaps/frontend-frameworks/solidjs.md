# SolidJS

## One-liner

The fine-grained reactive UI framework that looks like React but performs like vanilla JS — JSX + signals + no virtual DOM = the fastest React-like framework in 2026 benchmarks.

## What It Is

[SolidJS](https://www.solidjs.com/) is a declarative JavaScript library for building user interfaces with **fine-grained reactivity**. It uses JSX like React but compiles to direct DOM updates — no virtual DOM, no re-renders.

The 2026 baseline is **Solid 1.9+ / 2.x**:

- **Signals** — reactive primitives (similar to Vue 3 refs, MobX, Knockout).
- **Stores** — for nested reactive state.
- **Effects** — side effects that auto-track dependencies.
- **Control flow components** — `<Show>`, `<For>`, `<Switch>`.
- **SolidStart** — full-stack meta-framework (SSR + SPA + endpoints).
- **Solid Router** — official router.
- **TypeScript-first** — excellent types.

Adoption: Solid is the **fastest React alternative** in 2026 benchmarks. Used by Chrome DevTools team (Angular's bench for ngFor), parts of GitHub, indie devs who want React DX with better perf.

## When To Use It

- **You want React DX + better perf** — Solid's sweet spot.
- **You love fine-grained reactivity** — signals are explicit.
- **You need maximum performance** — Solid is at the top of benchmarks.
- **You're building a small-to-medium SPA** — no SSR needed.

## When NOT To Use It

- **You want React ecosystem** — React wins.
- **You need SSR-first** — SolidStart is improving but newer.
- **Massive hiring pool** — React wins.
- **You want the safest enterprise choice** — React / Angular.

## Why It Matters in 2026

SolidJS gives you React's JSX DX with fine-grained reactivity (no virtual DOM). Solid 1.9/2.x + SolidStart is a complete stack. Solid is at the top of performance benchmarks among React-like frameworks in 2026.
