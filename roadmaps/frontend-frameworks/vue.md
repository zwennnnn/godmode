# Vue.js

## One-liner

The progressive, incrementally-adoptable JavaScript framework for building UIs — Evan You's answer to "what if Angular and React had a baby?" — the #2 frontend framework after React in 2026.

## What It Is

[Vue.js](https://vuejs.org/) is a progressive framework for building user interfaces. It's designed to be incrementally adoptable — can scale from a library drop-in to a full SPA. Combines Angular's template syntax with React's component model + reactivity.

The 2026 baseline is **Vue 3.5+**:

- **Composition API** — function-based components (preferred since Vue 3).
- **`<script setup>`** — terser syntax.
- **Reactivity** — Proxy-based; fine-grained.
- **Pinia** — official state management (replaced Vuex).
- **Vue Router 4** — official router.
- **Nuxt 3+** — full-stack meta-framework (SSR + SSG + SPA).
- **Vite** — default build tool.
- **Vitest** — default test framework.

Adoption: Vue is the **#2 frontend framework** by GitHub stars + npm downloads after React. Massive in China + Asia + Europe; loved by devs who find React too JSX-heavy.

## When To Use It

- **You want a gentle learning curve** — Vue's templates + docs are widely praised.
- **You prefer Composition API or Options API** — both supported.
- **You want HTML-like templates** — Vue's templates are HTML.
- **You want an end-to-end solution** — Vue + Vue Router + Pinia + Vite + Vitest.
- **You want full-stack** — Nuxt 3 with Nitro server.
- **You want Chinese ecosystem** — Vue is huge in China.

## When NOT To Use It

- **You want React** — use React.
- **You want maximum JS / TS ergonomics** — React TSX has better types.
- **Massive enterprise with React skills** — stick with React.

## Why It Matters in 2026

Vue 3 + Composition API + Pinia + Nuxt 3 + Vite + Vitest is a complete end-to-end stack. Vue is the #2 frontend framework by npm downloads and is loved for its gentle learning curve. For teams that want React DX without React JSX, Vue is the default.
