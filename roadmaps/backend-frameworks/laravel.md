# Laravel

## One-liner

The PHP web framework with the best developer experience — elegant syntax, batteries-included, and Laravel 11+ in 2026 is the most productive PHP web framework by a wide margin.

## What It Is

[Laravel](https://laravel.com/) is a PHP web framework with expressive, elegant syntax. It provides routing, ORM (Eloquent), templating (Blade), queues, mail, auth, validation, caching, and more out of the box.

The 2026 baseline is **Laravel 11+ / 12+**:

- **Streamlined structure** — fewer default files.
- **Laravel 12** — concurrency support, workerman / roadrunner integration.
- **Eloquent ORM** — ActiveRecord-style.
- **Blade** templating + **Livewire** for reactive components.
- **Inertia.js** + Vue/React for SPA mode.
- **Sanctum** for API tokens / SPA auth.
- **Forge** (server management) + **Vapor** (serverless on AWS Lambda).
- **Nova** (admin panel, paid).

Adoption: Laravel is the **most popular PHP framework** by usage, ecosystem size, and developer love. ~750K+ developers.

## When To Use It

- **PHP web app / API** — Laravel's sweet spot.
- **Full-stack with Livewire** — minimal JS needed.
- **SPA via Inertia + Vue/React** — full flexibility.
- **You want batteries-included** — auth, mail, queues, etc.
- **Serverless** — Vapor on AWS Lambda.

## When NOT To Use It

- **You don't use PHP** — wrong framework.
- **You want maximum performance** — Go / Rust better.
- **You want minimal framework** — Laravel is opinionated.

## Why It Matters in 2026

Laravel 11/12 streamlined the framework; Laravel 12 added workerman / roadrunner integration for true concurrency. Laravel remains the most productive PHP framework; Vapor enables serverless on AWS Lambda. Default for PHP web apps in 2026.
