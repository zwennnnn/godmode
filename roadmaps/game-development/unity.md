# Unity

## One-liner

The most popular game engine for mobile, indie, and cross-platform 3D/2D — used by half of all mobile games and thousands of indie titles — with C# scripting, vast asset store, and AI features in 2026.

## What It Is

Unity is a cross-platform game engine with a visual editor, C# scripting, a massive asset store, and deploy targets covering mobile, console, PC, web, and XR. It powers ~50% of mobile games and is dominant in indie and mobile game development.

The 2026 baseline is **Unity 6.x** (Unity 6 released in 2024):

- **Unity 6 LTS** — stable production.
- **Render Graph** — modern rendering pipeline (URP / HDRP).
- **DOTS (Data-Oriented Tech Stack)** — Entity Component System + Burst compiler for high-performance code.
- **Unity Sentis** — on-device ML inference (run neural networks in your game).
- **Unity Muse** — AI-assisted content generation (sprites, animations, textures).
- **Unity Cloud** — multiplayer services, analytics, monetization.
- **WebGPU** support — modern web graphics.
- **Adaptive Performance** — dynamic device scaling.

### Dominant platforms for Unity

- **Mobile** — ~50% of mobile games are Unity-built.
- **Indie PC** — Hollow Knight, Cuphead, Among Us, Hades (early builds).
- **VR / AR** — Vision Pro + Meta Quest.
- **WebGL** — playable in browser.
- **Console** — Switch, PS5, Xbox.

Adoption: Unity is **#1 for mobile gaming** and **#1 for indie game development**. Used by >1.5M monthly active developers. Major titles: Pokémon Go, Among Us, Hollow Knight, Genshin Impact (early versions), Monument Valley.

## When To Use It

- **Mobile game** — Unity is the default.
- **Indie 2D / 3D game** — Unity asset store + C# is the easiest path.
- **Cross-platform** — write once, deploy everywhere (mobile + console + PC + web).
- **AR / VR** — Vision Pro, Meta Quest, ARKit, ARCore.
- **Rapid prototyping** — fast iteration.
- **You want to learn game dev** — Unity has the biggest learning community.

## When NOT To Use It

- **AAA 3D cinematic** — Unreal Engine is better.
- **Pure 2D pixel art with minimal overhead** — Godot is lighter + simpler.
- **You hate C#** — Unreal uses C++; Godot uses GDScript.
- **Open-source requirement** — Unity is proprietary (free tier, not open source).
- **You need ultra-tight performance** — Unreal C++ or custom engines.

## Why It Matters in 2026

Three forces:

1. **Unity 6 stabilized.** Render Graph, DOTS, AI features — Unity is competitive with Unreal for mid-range 3D. The "Unity is janky" era is over.
2. **AI-assisted game dev.** Unity Muse (AI sprite / texture generation), Sentis (on-device ML), AI playtesting.
3. **Mobile + indie remain dominant.** Despite the Epic-Unreal-mobile push, Unity wins mobile. Half of mobile games.

Practitioner playbook in 2026:
1. **Install Unity 6 LTS** + Visual Studio / Rider.
2. **Start with Unity Learn** — free tutorials.
3. **Asset Store** — buy / use free assets; don't reinvent.
4. **URP (Universal Render Pipeline)** — modern default.
5. **DOTS / ECS** — for performance-critical games.
6. **Unity Cloud** — for multiplayer + analytics + monetization.
7. **Ship a small game** — jam or itch.io.

## Comparison With Alternatives

| Alternative | Better when | Worse when |
|-------------|-------------|------------|
| **Unreal Engine** | AAA 3D; cinematic; VR (high-fidelity). | Mobile; small indie. |
| **Godot** | Open-source; 2D; small indie. | AAA; mobile scale. |
| **Custom engine** | You need something unique. | You want productivity. |
| **Unreal / Unity hybrid** | Use Unity for mobile, Unreal for PC/console. | You want one engine. |
