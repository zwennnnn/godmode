# Godot

## One-liner

The MIT-licensed, open-source game engine that became the indie / 2D favorite — lightweight, fast, GDScript + C# support, and free for any use — the third pillar alongside Unity and Unreal.

## What It Is

Godot is a fully open-source (MIT) game engine with a lightweight editor, GDScript (Python-like) scripting language, optional C# support, and strong 2D support. It runs on every desktop OS, exports to every platform, and is beloved by indie devs.

The 2026 baseline is **Godot 4.x** (Godot 4 released 2022):

- **Godot 4** — Vulkan-based renderer; physically-based rendering; global illumination.
- **GDScript 2.0** — typed; modern; still Python-like.
- **C# support** — .NET 8+.
- **GDExtension** — C++ extensions (replaces GDNative).
- **TileMap + 2D workflow** — best-in-class 2D.
- **Visual shader editor**.
- **Navigation** — 2D + 3D navigation regions.
- **Multiplayer** — high-level multiplayer API (MultiplayerSpawner, MultiplayerSynchronizer).
- **Web export** — WebAssembly.
- **Mobile + console export** — iOS, Android, Switch, etc.

Adoption: Godot's growth has been explosive since 4.0. Steam survey 2024: Godot overtook Unity in "most-used engine" among indie devs on Steam. ~3M+ developers. Used by hundreds of successful indie titles (Cassette Beasts, Brotato, Dome Keeper, Ender Lilies).

## When To Use It

- **Open-source requirement** — Godot is MIT.
- **2D game** — Godot 2D is best-in-class.
- **Indie 3D** — Godot 4 is capable for 2D-leaning 3D.
- **You want lightweight + fast** — editor loads in seconds; binary is small.
- **You hate C++** — GDScript is Python-like; C# also supported.
- **You can't pay for Unity Pro** — Godot is fully free.
- **Education / game jams** — quick to learn; great community.

## When NOT To Use It

- **AAA 3D cinematic** — Unreal is better; Godot's 3D is good but not UE-level.
- **Mobile scale** — Unity has more mature mobile tooling.
- **You depend on a specific Unity / Unreal asset** — Godot's marketplace is smaller.
- **You need C++** — use C# in Godot, or Unreal / custom engine for C++.
- **You need console SDK maturity** — Unity / Unreal have longer console track records.

## Why It Matters in 2026

Three forces:

1. **Indie momentum shifted to Godot.** Steam Next Fest is dominated by Godot titles; the "indie engine" label is now Godot's, not Unity's.
2. **Unity's pricing drama** — Unity's 2023 runtime fee + install fee controversy pushed many devs to Godot. The drama drove permanent migration.
3. **Open source + freedom** — Godot is MIT; no royalties; no install fees; forever.

Practitioner playbook in 2026:
1. **Install Godot 4** — single binary; no installer needed.
2. **Start with GDScript** — easy to learn.
3. **Built-in tutorials** — "Your first 2D game" + "Your first 3D game".
4. **Asset Library** — free assets from community.
5. **C# if you prefer** — Visual Studio / Rider integration.
