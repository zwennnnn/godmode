# Unreal Engine

## One-liner

Epic Games' AAA-grade 3D engine with cinematic rendering, C++ power, Blueprint visual scripting, and free for indie — the choice for serious 3D games, film VFX, simulation, and high-fidelity VR.

## What It Is

Unreal Engine (UE) is Epic Games' flagship game engine, used for AAA console / PC titles, high-end mobile games, film VFX, architectural visualization, automotive, and more. It's known for cinematic rendering, C++ performance, and the Blueprint visual scripting system.

The 2026 baseline is **Unreal Engine 5.7+** (UE5 released 2022):

- **Lumen** — real-time global illumination + reflections; no bake required.
- **Nanite** — virtualized micropolygon geometry; millions of triangles in real time.
- **MetaHuman** — photorealistic digital humans.
- **World Partition** — streaming open worlds.
- **Nanite + Lumen + MetaHuman** = the modern UE5 stack.
- **Lyra sample game** — production-quality starter.
- **Verse** — new scripting language for UEFN (Unreal Editor for Fortnite).
- **UEFN** — Unreal Editor for Fortnite; creative mode.
- **Mass AI** — crowd simulation at scale.
- **Chaos Physics** — destruction + physics.

### Licensing

| Use | Cost |
|-----|------|
| **Game / non-game revenue < $1M** | Free (5% royalty above $1M). |
| **Game revenue ≥ $1M** | 5% royalty on revenue above $1M. |
| **Film / TV / entertainment** | Free. |
| **Architecture / automotive / consulting** | Free. |
| **Fortnite (UEFN)** | Specific license terms. |

Adoption: Unreal powers most AAA console + PC games. Fortnite (Epic's own), Final Fantasy VII Remake, Kingdom Hearts IV, Mass Effect Legendary Edition, many VR titles. Also used in The Mandalorian (ILM StageCraft), automotive (BMW factory planning), architecture.

## When To Use It

- **AAA 3D game** — UE's home turf.
- **Cinematic / photorealistic visuals** — Nanite + Lumen are best-in-class.
- **Open-world games** — World Partition handles streaming.
- **VR / high-fidelity XR** — UE is the default.
- **Film / VFX / Virtual production** — ILM StageCraft, Mandalorian.
- **Architectural / automotive visualization** — real-time walkthroughs.
- **You have C++ experience** — UE is native C++.

## When NOT To Use It

- **Mobile (default)** — UE5 mobile is possible but heavy; Unity is easier.
- **2D games** — overkill; Godot or Unity 2D better.
- **Indie with no 3D artists** — Unity or Godot is easier.
- **You hate C++** — Blueprint is fine but limited for systems code.
- **Open-source requirement** — UE is source-available, not OSI-open.
- **You can't afford 5% royalty** — Unity Personal is fully free; Godot is free.

## Why It Matters in 2026

Three forces:

1. **Nanite + Lumen set the visual bar.** UE5's photorealistic rendering in real time is unmatched. Console + PC AAA titles default to UE.
2. **UEFN + Fortnite** — Fortnite as a platform; creators build experiences with UE.
3. **Film + automotive adoption.** ILM StageCraft, BMW, automotive HUDs — UE for non-games.

Practitioner playbook in 2026:
1. **Install UE5** — Epic Games Launcher.
2. **Start with Lyra** — production-quality sample.
3. **Learn Blueprint + C++** — visual scripting for prototypes; C++ for systems.
4. **Nanite + Lumen** — the modern rendering stack.
5. **Asset Marketplace** — buy / use free assets.
6. **Multiplayer** — Unreal has built-in replication; or use EOS (Epic Online Services) for cross-platform.
