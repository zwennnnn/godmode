# Game Developer

## One-liner

The full-stack discipline of building video games — game design, programming, art, audio, production, business — for indie, AAA, mobile, console, PC, and web.

## What It Is

Game development is the process of designing, programming, art-directing, producing, testing, and shipping interactive entertainment. It spans:

| Discipline | What |
|------------|------|
| **Game design** | Mechanics, systems, narrative, level design, balance. |
| **Programming** | Engine usage, gameplay code, tools, networking, AI. |
| **Art** | 2D / 3D / animation / VFX / UI. |
| **Audio** | Music, sound design, voice. |
| **Production** | Project management, scheduling, QA. |
| **Business** | Marketing, monetization, distribution, community. |
| **QA / Testing** | Functional, performance, compatibility, localization. |

### The 2026 game development stack

| Layer | Tools |
|-------|-------|
| **Engines** | Unity, Unreal Engine, Godot (see individual files). |
| **Languages** | C# (Unity), C++ (Unreal), GDScript / C# (Godot), Rust (Bevy), Lua (Roblox). |
| **Art** | Blender, Maya, ZBrush, Photoshop, Substance Painter. |
| **Audio** | FMOD, Wwise, Audacity. |
| **Version control** | Git + Git LFS, Perforce Helix Core (large AAA), Plastic SCM. |
| **Project management** | Jira, Linear, HacknPlan (game-focused). |
| **Analytics** | Unity Analytics, GameAnalytics, deltaDNA. |
| **Multiplayer** | Photon, Mirror, Netcode for GameObjects, Nakama, PlayFab Multiplayer. |
| **Distribution** | Steam, Epic Games Store, itch.io, App Store, Google Play, consoles. |

### Career paths

| Path | What |
|------|------|
| **Indie / Solo dev** | Small team (1–5); ship on Steam / itch.io; can be full-stack. |
| **Studio (small)** | 10–50 people; roles specialized. |
| **Studio (AAA)** | Hundreds to thousands; roles hyper-specialized. |
| **Mobile / Live ops** | Ongoing content updates; monetization heavy. |
| **Tools / Engine dev** | Build tools for game developers. |
| **Indie publisher** | Help indie devs ship + market. |

Adoption: Game development is a massive global industry. ~$200B+ market in 2026; millions of developers. Steam alone has >100K games. Engines are free (Unity / Godot) or royalty-only (Unreal); indie distribution is open (itch.io, Steam).

## When To Use It

- **You want to build a game** — period.
- **You're making an interactive product** — gamification; game-adjacent.
- **You want to learn programming** — game dev is fun + visual.
- **You want a creative / artistic outlet** — game dev combines code + art + design.

## When NOT To Use It

- **You want a quick SaaS / web app** — use a web framework.
- **You hate creative constraints** — game dev has many.
- **You can't ship a finished product** — most games are abandoned; you need follow-through.
- **You want quick ROI** — game dev is high-risk, long-tail.
- **You don't have a story / mechanic** — start with the idea, not the engine.

## Why It Matters in 2026

Three forces:

1. **Engines democratized.** Unity, Unreal, Godot are all free for indie; tools like Blender + MagicaVoxel made art accessible; AI-assisted art / animation accelerated production.
2. **AI is changing game dev.** AI-generated textures, AI NPCs, AI playtesting, AI-assisted coding. Game studios are integrating AI fast.
3. **Cloud + multiplayer + live ops** are standard. Free-to-play, seasonal content, battle passes, microtransactions — the business model.

Practitioner playbook in 2026:
1. **Pick an engine**: Unity (mobile / 2D), Unreal (3D / AAA), Godot (indie / OSS).
2. **Start with a small game** — finish it; ship it.
3. **Learn game design fundamentals** — see [game-design.md](game-design.md).
4. **Iterate publicly** — Steam Next Fest, itch.io, devlogs.
5. **Join a community** — r/gamedev, IGDA, game jams.
