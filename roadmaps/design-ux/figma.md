# Figma and Design Tools

## One-liner

The browser-based, collaborative design tool that became the default for UI design in 2026 — with built-in prototyping, dev mode, design tokens, and AI features.

## What It Is

Figma is a vector graphics editor + prototyping tool that runs in the browser, supports real-time collaboration (like Google Docs for design), and ships with a developer handoff mode. It overtook Sketch + Adobe XD as the dominant UI design tool by 2022 and hasn't looked back.

### The 2026 Figma ecosystem

| Feature | Description |
|---------|-------------|
| **Canvas + Components** | Vector design with reusable components, variants, instances. |
| **Auto Layout** | Responsive layouts that adapt to content. |
| **Variables + Modes** | Design tokens (color, spacing, typography) with light/dark modes. |
| **Prototyping** | Interactive flows with overlays, scroll, hover, animations. |
| **Dev Mode** ([dev.figma.com](https://www.figma.com/dev-mode)) | Developer view with code snippets (CSS, Tailwind, React, iOS, Android), tokens export, VS Code extension. |
| **Figma Slides** | Presentation mode. |
| **FigJam** | Whiteboard for brainstorming. |
| **Figma AI** ([AI features](https://help.figma.com/hc/en-us/articles/18916952217111-Get-started-with-Figma-AI)) | Generate layouts from prompts, write copy, suggest components. |
| **Plugins** | Huge ecosystem (Unsplash, Iconify, Stark for a11y, Content Reel for placeholder copy, etc.). |
| **Community** ([community.figma.com](https://www.figma.com/community)) | Free UI kits (Material, iOS, Tailwind UI), templates. |

### Alternatives

| Tool | Notes |
|------|-------|
| **[Sketch](https://www.sketch.com/)** | macOS only; pioneered modern UI design; lost to Figma. |

## When To Use It

### Figma
- **Default for UI design** in 2026.
- **Collaborative design** — multiple designers in real time.
- **Design system authoring** — Variables + Components + Auto Layout.
- **Designer-developer handoff** — Dev Mode + tokens export.
- **Prototyping flows** — interactive prototypes for user testing.
- **AI-assisted design** — Figma AI generates layouts.

### Sketch
- **macOS-only team** that's standardized on it.
- **Long-time Sketch user** — migration cost is real.

### Framer
- **Marketing sites / landing pages** — design + publish in one.
- **You want code-quality React output.**

### Penpot
- **Open-source requirement.**
- **Self-host preference.**

### Adobe XD
- **Avoid** — discontinued.

## When NOT To Use It

### Figma
- **Print design** — InDesign / Affinity Publisher.
- **Illustration** — Illustrator / Procreate.
- **Brand identity / logos** — Illustrator.
- **3D / motion** — Cinema 4D / After Effects.

### Any design tool
- **You don't design** — code-only projects.

## Why It Matters in 2026

Three forces:

1. **Figma is the standard.** Every new designer learns it; every team uses it. The competitor graveyard (XD, InVision, Sketch's market share) confirms it.
2. **Dev Mode + design tokens closed the design-code gap.** Tokens flow from Figma to CSS / Tailwind / iOS / Android automatically. Devs get code snippets; designers see production.
3. **Figma AI + plugins** — AI generates layouts from prompts; plugins for everything else. Productivity multiplier.

Practitioner playbook in 2026:
1. **Figma for design**, Dev Mode for handoff.
2. **Variables + Modes** for tokens.
3. **Auto Layout** for responsive designs.
4. **Plugins**: Stark (a11y), Iconify, Unsplash, Content Reel.
5. **Figma AI** for quick mockups + exploration.
6. **Style Dictionary / Tokens Studio** to export to code.
