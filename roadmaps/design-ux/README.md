# Design and UX

> **Category:** The disciplines and tools that turn products from functional into delightful — UX research, product design, design systems, design tools, accessibility, and user research.
> **Sources:** [roadmap.sh/ux-design](https://roadmap.sh/ux-design), [roadmap.sh/product-design](https://roadmap.sh/product-design), [roadmap.sh/design-system](https://roadmap.sh/design-system)

This roadmap covers what every product team needs beyond code: how to understand users, design experiences, build consistent interfaces, ensure accessibility, and ship products that people love. Designers, design engineers, PMs, and founders all live here.

## Quick Decision Guide

### If you're a designer

Start with [ux-design.md](ux-design.md) for fundamentals + heuristics. Then [figma.md](figma.md) for tools. Then [design-system.md](design-system.md) for consistency.

### If you're a PM / founder

Start with [product-design.md](product-design.md) + [user-research.md](user-research.md). Apply JTBD + Continuous Discovery.

### If you're an engineer doing design work

Start with [figma.md](figma.md) + [design-system.md](design-system.md) + [accessibility.md](accessibility.md). shadcn/ui + Tailwind v4 for code-side.

### If you need to make your app accessible

[accessibility.md](accessibility.md) — WCAG 2.2 AA is the legal baseline (ADA + EU EAA).

### If you're building a design system from scratch

[design-system.md](design-system.md) — shadcn/ui + Tailwind v4 + tokens is the modern default.
