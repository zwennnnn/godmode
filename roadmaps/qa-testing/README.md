# QA and Testing

> **Category:** The practices + tools that keep quality high — software testing fundamentals, QA processes, code review, end-to-end testing with Playwright + Cypress.

## Quick Decision Guide

### If you're starting a QA practice

Read **[QA](qa.md)** + **[Software Testing](software-testing.md)**.

### If you're a team lead setting up reviews

**[Code Review](code-review.md)** — Conventional Comments + small PRs + fast turnaround.

### If you ship a web app + want best E2E

**[Playwright](playwright.md)** — multi-browser; trace viewer; codegen.

### If you ship a web app + want simplest E2E

**[Cypress](cypress.md)** — best time-travel debugger; component testing.
