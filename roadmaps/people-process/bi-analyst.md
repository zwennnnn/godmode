# BI Analyst

## One-liner

The role that turns business data into actionable insights — builds dashboards, reports, and analyses that drive decisions; the translator between data and business stakeholders.

## What It Is

A [BI (Business Intelligence) Analyst](https://roadmap.sh/bi-analyst) focuses on reporting, dashboards, and business analysis — distinct from data scientists (predictive) and data engineers (pipelines). In 2026, BI analysts use modern self-service BI tools and increasingly AI-assisted analysis.

The 2026 stack:

| Layer | Tools |
|-------|-------|
| **BI Platforms** | Tableau, Power BI, Looker, Metabase, ThoughtSpot, Mode, Hex. |
| **Data Warehouse** | Snowflake, BigQuery, Databricks, Redshift. |
| **SQL** | The lingua franca (see [`../databases/sql.md`](../databases/sql.md)). |
| **ETL** | dbt, Fivetran, Airbyte. |
| **Reverse ETL** | Hightouch, Census. |
| **AI / NL queries** | ThoughtSpot, Mode AI, Hex AI. |
| **Spreadsheets** | Excel / Google Sheets for ad-hoc. |

Adoption: Every mid+ company has BI analysts. They sit between data engineering and the business.

## When To Use It

- **You turn data into business decisions** — BI analyst.
- **You build dashboards** — BI tools.
- **You write SQL daily** — SQL fluency.

## When NOT To Use It

- **You build pipelines** — data engineer.
- **You build predictive models** — data scientist.

## Why It Matters in 2026

Three forces: (1) AI-assisted BI — natural-language queries are real; (2) Self-service BI dominates — Tableau + Power BI + Looker + Metabase; (3) Data warehouse + BI tool is the default stack.

Practitioner playbook: (1) Master SQL; (2) Pick one BI tool deeply; (3) Self-service dashboards; (4) AI-assisted exploration; (5) Define KPIs with stakeholders; (6) Document data sources.

## Comparison With Alternatives

| Alternative | Better when | Worse when |
|-------------|-------------|------------|
| **Data engineer** | Build pipelines. | Self-service analysis. |
| **Data scientist** | Predictive models. | Reporting. |
| **Analyst without BI tool** | Ad-hoc. | Recurring dashboards. |
| **PM with dashboard access** | Quick view. | Deep analysis. |
