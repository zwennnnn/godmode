## Quick Decision Guide

### If you lead product strategy

**[Product Manager](product-manager.md)** — OKRs, JTBD, continuous discovery.

### If you lead an engineering team

**[Engineering Manager](engineering-manager.md)** — people + process + technical judgment.

### If you're a developer advocate / DevRel

**[DevRel](devrel.md)** — content + community + OSS.

### If you write documentation

**[Technical Writer](technical-writer.md)** — Diátaxis + docs-as-code + AI-assisted.

### If you build dashboards for business users

**[BI Analyst](bi-analyst.md)** — SQL + Tableau / Power BI / Looker / Metabase.

### If you design + operate networks

**[Network Engineer](network-engineer.md)** — BGP / OSPF / firewalls / cloud networking.
